# Lucky Sir Jaipur Academy 📚

A professional study platform for competitive exam preparation.

## 🎯 Supported Exams

- **Federal**: SSC GD, SSC CGL, SSC MTS, SSC CPO
- **State**: RAS (RPSC), BSTC, Patwari, Teacher, REET, 4th Grade
- **Defence**: Indian Army

## ✨ Features

✅ Modern RWA-inspired UI Design
✅ 11+ Competitive Exams Covered
✅ Subject-wise Content Organization
✅ Mobile Responsive Design
✅ YouTube Integration Ready
✅ Beautiful Animations & Transitions
✅ SEO Optimized

## 🛠 Tech Stack

- **Frontend**: Next.js 14, React 18, TypeScript
- **Styling**: Tailwind CSS, Framer Motion
- **Icons**: React Icons
- **Deployment**: Vercel

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Set environment variables
cp .env.local .env.local.example

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## 📁 Project Structure

```
src/
├── app/          # Next.js pages
├── components/   # Reusable components
├── config/       # Configuration
└── styles/       # Global styles
```

## 🚢 Deploy to Vercel

```bash
npm i -g vercel
vercel
```
